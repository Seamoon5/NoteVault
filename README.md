# NoteVault

A fast, private note-taking app for Android, with an encrypted vault for
sensitive notes. Built with Kotlin, Jetpack Compose and Material 3.

Tuned for the Redmi Note 11 (Snapdragon 680, 90Hz AMOLED, Android 11 / MIUI /
HyperOS) but works on any Android 8.0 (API 26) phone or newer.

---

## What it does

### Notes
- Title + body, Google Keep style
- 7 colour-coded note backgrounds
- Pin important notes to the top
- Folders (unlimited) and tags (unlimited)
- Instant search across title, text and tags
- Two layouts: **grid** (2 per row) or **list** (one per row)
- Rename and delete folders, with a confirmation step

### Encrypted vault
- A separate space for secret notes, protected with a PIN
- **AES-256-GCM** encryption. The key is generated inside Android's Keystore
  (secure hardware on the phone) and is never readable by the app
- Your PIN is never stored. Only a **PBKDF2 / SHA-256** hash (120,000 rounds)
  plus a random salt is kept, so the PIN cannot be recovered from the app's data
- Unlock with **PIN or fingerprint**
- **Screenshots and screen recording are blocked** inside the vault
- The vault is **hidden from the Recent Apps switcher** (no thumbnail is shown)
- **Auto-locks** the instant you switch away from the app
- Change your PIN, or erase the whole vault, from Settings

### Export
- Any single note, or all notes, exported to **Markdown (.md)** or
  **Plain text (.txt)**
- Android's normal "save as" dialog is used, so you choose the folder -
  including any cloud drive you already use
- Nothing is ever uploaded to any server

### Appearance
- Material 3 design with a custom violet brand colour
- Light / Dark / Follow-system theme
- A frosted-glass style background (see note below)
- Custom adaptive app icon and splash screen

## Build it yourself

Requirements: JDK 17, Android SDK with platform 35, Gradle 8.7.

```bash
# point the build at the SDK (edit if yours is elsewhere)
echo "sdk.dir=/path/to/Android/Sdk" > local.properties

JAVA_HOME=/path/to/jdk-17 gradle assembleDebug
```

The APK appears at `app/build/outputs/apk/debug/app-debug.apk`.

### App icon

The launcher icon is not a hand-made PNG. It is generated by a small pure
Python script using only the standard library:

```bash
python3 tools/make_icon.py legacy     192 mipmap-xxxhdpi/ic_launcher.png
python3 tools/make_icon.py foreground 432 mipmap-xxxhdpi/ic_launcher_foreground.png
```

Change the colours or shapes at the top of `make_icon.py` and re-run to
regenerate every density. The script supersamples 3x3 for smooth edges.

### Two databases on purpose

| File | Holds | Protection |
| --- | --- | --- |
| `note-vault.db` | regular notes, folders | plain text, inside the app sandbox |
| `note-vault-vault.db` | secret notes | title/body/tags stored as AES-256 ciphertext |

Splitting them means the vault notes are unreadable even by accident, and a
future backup of regular notes can never leak the vault.

## Things worth knowing

**The "glass" effect is not real blur.** Genuine background blur needs
Android 12 or newer. This phone runs Android 11, so the frosted look is built
from a see-through gradient instead. It looks close and costs almost no
battery.

**A lost PIN means lost vault notes.** That is the point of encryption - nobody
can decrypt your notes without your PIN, including us. If you forget it, the
only option is to erase the vault and start again. The app tells you this
clearly on the lock screen.

**The Keystore key lives on this phone.** If you uninstall the app, the key
is destroyed and the vault notes cannot be recovered. Copy anything important
out with the Markdown export first.

**Search uses `LIKE`, not a full-text index.** For personal note counts
(hundreds, not hundreds of thousands) this is instant and keeps the database
simple. A larger app would want Room's FTS4.
